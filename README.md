# CPFRA-X — الدراسات المستقبلية للسياسات الثقافية من منظور اقتصادي ومنظور فكري

**مسارات تباعد القيمة: نموذج استشرافي لديناميكيات القيمة الاقتصادية والفكرية في السياسات الثقافية حتى ٢٠٥٠**

د. ماجد عبدالله بوشليبي · أكتوبر ٢٠٢٦

يضم هذا المستودع المخطوطة العربية الموسعة ومخرجاتها وكل ملفات العمليات التي أنتجتها (عدا الاستدعاء الأصلي، فهو خاص لا يُنشر): الشيفرة، والبيانات، والمراجع، وتقرير التحكيم الداخلي، وميثاق إدارة الدراسات المستقبلية في منصة CIRP ووكلاءها ومهاراتها.

## الحالة

| البند | الحالة |
| --- | --- |
| المخطوطة العربية | مكتملة ومحكَّمة داخلياً (نحو ١٦٬٣٠٠ كلمة في المتن) |
| حكم التحكيم الداخلي | صالح للتقديم إلى دورية عربية محكّمة؛ تعديلات طفيفة قبل النسخة الإنجليزية |
| المراجع | ٦١ مرجعاً بنظام APA 7 (٧ عربية و٥٤ أجنبية)، مطابقة آلياً مع الاستشهادات |
| Word / PDF | RTL، Noto Naskh Arabic، ١٢٣ حاشية سفلية حقيقية، ٥٤ صفحة |
| النسخة الإنجليزية للدورية | لم تُنجز بعد |

## بنية المستودع

```
manuscript/            المخطوطة المدمجة (Markdown) وأقسامها منفصلة في sections/
word/                  نسخة Word (.docx) ونسخة PDF
review/                تقرير التحكيم الداخلي والتحقق من النزاهة
data/                  قاعدة الإحصاءات (CSV) والمراجع (BibTeX وRIS)
code/                  شيفرة المحاكاة والإحصاء وبناء Word والمراجع
futures_department/    ميثاق إدارة الدراسات المستقبلية، سجل الوكلاء، والمهارات (حزم .skill ومصادرها)
```

## إعادة إنتاج النتائج

```bash
pip install -r code/requirements.txt
python code/cpfra_model_simulation.py          # مصفوفة التأثير المتبادل، النموذج الديناميكي، اختبار الحساسية
python code/cpfra_statistics_power_fisher.py   # تحليل المحتوى، اختبار فيشر، تحليل القوة
```

بناء Word وPDF (يتطلب Node مع `docx@9` وLibreOffice):

```bash
node code/build_docx.js manuscript/CPFRA-X_Manuscript_AR.md out.docx            # نسخة Word (فقرات مضبوطة)
PDFMODE=1 node code/build_docx.js manuscript/CPFRA-X_Manuscript_AR.md pdf.docx  # نسخة PDF (فقرات يمنى؛ فهرس ثابت)
soffice --headless --convert-to pdf pdf.docx
python code/toc_pages.py pdf.pdf toc.json
TOCPAGES=toc.json PDFMODE=1 node code/build_docx.js manuscript/CPFRA-X_Manuscript_AR.md pdf.docx && soffice --headless --convert-to pdf pdf.docx
python code/make_bib.py                                                         # يولّد BibTeX وRIS من قائمة المراجع
```

ملاحظة تقنية: تُبنى نسخة PDF بفقرات محاذاة لليمين لأن ضبط الفقرات العربية مع الحواشي يعطّل محرك LibreOffice؛ ونسخة Word مضبوطة الفقرات، ويُحدَّث فهرسها تلقائياً عند فتحها في Word.

## الحدود المعلنة

- أدلة ثانوية دون عمل ميداني؛ استرجاع نطاقي منظّم لا مراجعة نطاقية مكتملة.
- درجات مصفوفة التأثير المتبادل واختبار المتانة حكمٌ للباحث، لم تُعرض على خبراء.
- معاملات النموذج افتراضية غير معايَرة؛ وكل رقم منه محاكاة لا بيانات.
- أربعة مؤشرات (E7، E8، E10، E11) منقولة من ملخصات إطلاق تقارير اليونسكو بانتظار مطابقتها على متنها.

## الإفصاح

استُعين في هذا العمل بنظام ذكاء اصطناعي في استرجاع الأدبيات، والتحقق المرجعي، وبرمجة المحاكاة، وصياغة المسودات، والتحكيم الداخلي. وراجع المؤلف المحتوى ويتحمل وحده مسؤوليته العلمية. لا علامات مائية مخفية في أي ملف.

## الحقوق

جميع الحقوق محفوظة للمؤلف ما لم يُضف ترخيص صريح. المراجع المستشهد بها ملك لأصحابها.
